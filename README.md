# REWORN SHOP

REWORN SHOP is a second-hand clothing e-commerce website that I'm building as a portfolio project.

The project is built with React and JavaScript.

## Tech Stack

- React
- Vite
- JavaScript
- CSS
- React Router
- Git & GitHub

## Features

- Login & Sign Up
- Forgot Password
- Verification Code
- Reset Password
- Form Validation
- Loading States
- Error Handling
- Responsive Layout
- Responsive Navbar
- Search Bar
- Category Navigation
- Mega Menu
- Mobile Navigation Menu
- Cart Navigation

The authentication flow is currently frontend only and will be connected to a backend later.
