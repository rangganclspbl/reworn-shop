# REWORN SHOP

REWORN SHOP is a second-hand clothing e-commerce website that I'm building as a portfolio project.

The project is built with React and JavaScript. I'm building it step by step while learning and applying frontend and full-stack development concepts.

## Tech Stack

- React
- Vite
- JavaScript
- CSS
- React Router
- Git & GitHub

## Features

### Authentication
- Login & Sign Up
- Forgot Password
- Verification Code
- Reset Password
- Form Validation
- Loading States
- Error Handling

### Shopping Experience
- Home Page
- Product Listing
- Product Detail Page
- Product URL Routing
- Breadcrumb Navigation
- Search Bar
- Category Navigation
- Mega Menu
- Responsive Navbar
- Mobile Navigation Menu
- Responsive Layout

### Cart
- Add to Cart
- Cart Page
- Cart Item List
- Remove Item from Cart
- Empty Cart State
- Cart Total

The authentication flow is currently frontend-only and will be connected to a backend later.
